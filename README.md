# 📊 Amazon Yearly Sales Dashboard (Tableau Project)

This project showcases an interactive **Amazon Yearly Sales Dashboard** built with Tableau, using a dataset of Amazon transactions.  
The dashboard is designed to provide insights into sales, profit, and product category performance to support better business decision-making.

---

Explore the interactive dashboard on Tableau Public:  
👉 [E-Comm Sales Dashboard](https://public.tableau.com/app/profile/dhafin.tryadi/viz/E-CommSalesDashboard/Dashboard1?publish=yes)

- **README.md** → Overview of the project

---

## 📈 Dashboard Features
The dashboard highlights:
- **Sales & Profit Trends** → Analyze how sales and profit evolve over time
- **Top Product Categories** → Identify the best-performing product categories
- **Profitability Insights** → Compare sales vs. profit margins across categories
- **Interactive Filters** → Drill down by month, category, or sub-category
